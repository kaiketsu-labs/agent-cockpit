# Claude Deck

All your Claude Code sessions in one VS Code sidebar — organized by project folders and smart tickets (`PROJ-123`, `#42`, `owner/repo#42`), with silent automatic session & terminal tab naming, live activity status, prompt cache countdowns, Jira/GitHub status, and open PRs. Click any session to jump right into its terminal.

Works alongside the `deck` Claude Code plugin from the same repository. Setup and documentation: https://github.com/kaiketsu-labs/claude-deck
